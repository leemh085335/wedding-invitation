PUBLISH FREE VIA GITHUB PAGES
1. Sign in to github.com and create a public repository called wedding-invitation.
2. Upload index.html, this README.txt and the images folder containing main-portrait.png to the repository root.
3. In repository Settings > Pages, select Deploy from a branch, main, /(root), and Save.
4. Visit https://YOUR-USERNAME.github.io/wedding-invitation/ after Pages is deployed.
This ZIP is not itself a hosted website; GitHub account/repository access is needed to publish it.
